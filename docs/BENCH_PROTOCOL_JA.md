# モーターベンチのコマンドと記録

対象スケッチは `examples/nidec_bench/nidec_bench.ino`。RP2040-Zero、A28/B27、DIR26/PWM15/BRAKE14、INA219 SDA4/SCL5、Z相なしの試験用です。使用する電源とポートは各環境で確認してください。

## コマンド

Serialは115200、DTR=true、改行はLF。起動直後にモーターは動かない。

| コマンド例 | 内容 |
|---|---|
| `S` | 出力0、ブレーキON |
| `P 1500 1200` | 正のPWM指令1500/32767を1200ms、その後自動停止 |
| `P -5000 1000` | 負方向を1000ms |
| `I 50 1500` | 50mA目標のPI電流制御を1500ms |
| `R 32767 2000 3000` | 最大出力まで2秒で加速、3秒保持、2秒で減速して停止 |
| `V 20000` | 速度更新周期20ms。位置取得は1kHzのまま |
| `T 500000` | 停止タイムアウト500ms |
| `G 200` | エンコーダ取得のみ200ms休止。モーター停止タイマー/I²C/PIは継続 |
| `Z` | ソフトウェア原点リセット |
| `D` | INA219バス電圧、A/Bと制御ピンの電圧レベルを出力 |

PWM指令は±32767、電流目標は±1200mA、連続指令は最長10秒。
Rでは加速時間100〜4000ms、保持0〜8000ms、加速×2＋保持は10000ms以内。
INA219失敗またはシャント換算1600mA超でfaultをラッチして停止する。
再起動まで駆動コマンドを受け付けない。負論理PWMなので、実際の
analogWrite値は`32767 - abs(output)`。0指令は常時HIGH。
`D`のpwm_levelは瞬時値でありPWMデューティの測定ではない。

この実配線では正指令→rawカウント/速度が負、負指令→正だった。
表示は生符号のまま。電流の符号は元サンプル同様、出力指令から付与する。

## ホスト側の実行

付属の `tools/run-nidec-bench.ps1` がログ取得用です。送信時刻はホスト上の経過msで、finallyでSを送信します。USB切断時もファームウェアの指令時間制限で停止します。

```powershell
./tools/run-nidec-bench.ps1 -Port COM7 -LogName next-test.csv `
  -Commands @('0:S','200:V 10000','300:P 1500 1200','1800:S') -CaptureMs 2300
```

COM7は例です。実際のポートへ変更してください。ログは指定したパス（相対パスならカレントディレクトリ）へ保存します。

CSV列は以下。ログは約100Hzなので全ての1kHzサンプルを記録してはいない。
生シリアルを`.raw`、送信コマンドを`.commands`へ併記する。

```
host_tick_us,t_us,speed_t_us,count,substeps,speed,stopped,mode,demand,output,
current_ma,filtered_ma,samples,missed,max_read_us,max_work_us,i2c_errors,fault
```

- host_tick_usは名前に反して**マイコンのループ開始時刻**。
- t_usは取得時刻、speed_t_usは速度の更新時刻。
- G中はt_us/count等が保持され、samplesが増えない。
- max_work_usはエンコーダ/I²C/PI部分。USBログ出力は含めない。
  missedはログ処理を含む次回ループ開始の期限超過を数える。
- 速度更新周期は絶対期限を進めており、µsジッタによる累積ずれを避ける。
  遅れても過去の更新は再実行しない。

## 実機で確認したこと・残り

約179steps/sで停止誤判定なし、5/10/20msの速度周期、正逆回転、
50/-50/100mAのPI実行中の取得、200ms取得休止を挟む移動・停止を確認。
I²Cエラー、fault、1kHzのmissedはいずれも0。

PIは元サンプルのP=100/I=1000と実測dtを使用する。元サンプルの
固定delta=0.01とは実効積分作用が異なる。短時間の試験では電流目標に
まだ収束していないため、電流制御のチューニング完了とは扱わない。
原ライブラリの500msごとのストール保護解除パルスはこの短時間ベンチに
含めていない。無期限の位置保持用途にそのまま使わない。

長時間の最大出力連続運転、外部カウンタによる絶対精度は未検証です。このベンチはPico_PIO_Encoderを直接使用し、Nidecライブラリの導入を必要としません。下流ラッパーとの統合試験はVALIDATION_RESULTS.mdに別記しています。

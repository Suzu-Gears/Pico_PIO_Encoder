# 今後の候補

0.4.0では独立更新、64bit実測位置、コア間Snapshot、診断、終了・再初期化、連続／非連続A/B方式を実装済みです。Arduino・Pico SDKのビルド用CIを同梱しています。以下は今後の候補で、対応予定を保証するものではありません。

- **速度LPF**：推定の更新周期とは独立した時定数を持ち、可変dtに対応する。必要性を実測で確認してから検討。
- **超低速向け停止時間の適応化**：停止検出の遅延との交換条件を明示する。
- **1回転周期の誤差補正**：位相幅の4相校正とは別の補正。基準位置と再現性の検証が必要。
- **独立したハードウェア基準との比較**：絶対カウント精度、ノイズ耐性、実Z捕捉の測定。
- **RP2350実機検証の拡充**：両配線方式、コア間共有、上位GPIOウィンドウの実動作。
- **校正値の永続化例**：学習結果を保存し、起動時に復元する例。

要望はGitHub Issuesへ、用途・必要な周期・エンコーダ仕様とともにお寄せください。
